三 Quick Start

Install in Seconds

Clone once. Install once. The crew then works in whichever project you open.

git clone https://github.com/veeresh-bikkaneti/agent-call-sheet.git
cd agent-call-sheet
python3 bootstrap.py --list          # preview — writes nothing
python3 bootstrap.py                 # install front door + Rigor core
python3 bootstrap.py --template review-crew  # or cast a named crew
A bare run targets Claude Code (~/.claude/skills). For other surfaces use --target claude-web|grok-build|prompt-only to stage files for upload/paste.
⚡

Minimal (2 files)

python3 bootstrap.py --minimal --dest ~/skills — just the front door (orchestrator + starter prompt). No packs.

📦

Add Packs

python3 bootstrap.py --packs rigor,seo,legal --dest ~/skills — add specialist packs incrementally.

🎮

Zero-Install

Paste front-door/starter-prompt.md into any AI assistant. No files installed. Works everywhere.

五 Live Collaboration Debugger

Watch Live Intervene

Run the board server to watch crews live, send nudges, intervene mid-run. Rate limited (60 req/min + 10 burst). No auth — run on trusted network only.

# Terminal 1: Start server
python3 front-door/board-server.py --run-file crew-run.jsonl --port 8765

# Terminal 2: Test endpoints
curl http://127.0.0.1:8765/state
curl -X POST http://127.0.0.1:8765/events -H "Content-Type: application/json" -d '{"agent":"test","task":"x","phase":"BUILD","status":"running","artifact":"x"}'
curl -X POST http://127.0.0.1:8765/nudge -H "Content-Type: application/json" -d '{"agent":"test","message":"wake up"}'
curl -X POST http://127.0.0.1:8765/intervene -H "Content-Type: application/json" -d '{"action":"pause","agent":"test"}'
📡

SSE Stream

Real-time updates via GET /stream. Board reconnects auto on disconnect.

🔔

Nudge Silent Agents

POST /nudge — sends a message to a silent agent. Board shows "Nudged" badge.

🛑

Intervene Mid-Run

POST /intervene — pause, resume, redirect, reassign, or stop_run. Dynamic form per action.

📊

Rate Limited

Token bucket: 60 req/min + 10 burst. Returns 429 with Retry-After header.
