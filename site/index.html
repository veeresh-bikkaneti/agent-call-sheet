二 The Front Door

The Front Door

The way in. A starter prompt that sets 11 house rules — remember the user, think in graphs, evidence first, blocked means blocked, done means verified. And the Crew Orchestrator: a skill that turns your host agent into a crew coordinator.

Phases: confirm target → plan → build → test → independent gate → report. Staffs specialists by name. Never self-certifies; independent Reality Checker gates every wave.

📜

Starter Prompt

Sets the 11 house rules: remember the user, learn from habits, think in graphs, reply in ADHD shape, climb the laziness ladder, think before you code, evidence first, vet before adopt, blocked means blocked, done means verified, declare your mode.

🎭

Crew Orchestrator

Runs multi-agent work in phases: confirm target → plan → build → test → independent gate → report. Staffs specialists by name. Never self-certifies; independent Reality Checker gates every wave.

📦

Per-Surface Install

Claude Code, Claude web, Grok Build, Grok web, prompt-only. Verified and unverified claims labelled honestly in each guide.

Install the front door

git clone https://github.com/veeresh-bikkaneti/agent-call-sheet.git
cd agent-call-sheet
python3 bootstrap.py --list      # preview — writes nothing
python3 bootstrap.py             # install front door + Rigor core
python3 bootstrap.py --template review-crew  # or cast a named crew

A bare run targets Claude Code (~/.claude/skills). Other surfaces stage files for upload/paste. --bundle DIR writes one zip per entry + front-door.zip.

三 Live Collaboration

Live Debugger

Real-time observability + intervention for running crews. The board server streams run-status lines via SSE; the board renders agents live; you can pause, redirect, reassign, or stop any agent mid-run.

🖥️

Board Server

front-door/board-server.py — Python stdlib only. Serves board.html with injected marker, streams run file via SSE, folds state for GET /state, accepts POST /events, POST /nudge, POST /intervene.

🎮

Intervention API

5 actions: pause, resume, redirect, reassign, stop_run. Human clicks in board UI → POST /intervene → line appended to run file → coordinator relays to agent.

📚

Coordinator Library

front-door/live_debugger.py — LiveDebugger emits events to run file + server; InterventionClient lets humans pause/redirect/stop. Auto-heartbeat for active agents.

Run a live session

# Terminal 1: start the board server
python3 front-door/board-server.py --run-file crew-run.jsonl --port 8765

# Terminal 2: run your crew (uses live_debugger to emit events)
# Open http://127.0.0.1:8765/ in browser — watch agents live, click Intervene
四 Paperclip Bridge

Paperclip Bridge

--export-paperclip emits the agentcompanies/v1 schema with all Paperclip primitives — portable agent/team/task definitions you can hand to other tools.

📋

TEAM.md — includes[]

Array of sub-teams for hierarchical crews. Self-reference by default; extend for nested crews.

📁

PROJECT.md — owner

Manager entry as owner. Description and when-to-use carried over.

🏢

COMPANY.md — root config

Council rules, escalation paths (T1/T2/T3), budget defaults. New file at export root.

✅

TASK.md — recurring + assignee

Routines become tasks with recurring: true and assignee (manager). Ready for scheduling.

🔧

AGENTS.md — skills[]

Per-agent skills array when skill members present in crew. Maps to pack membership.

Export a Paperclip team

python3 bootstrap.py --template review-crew --export-paperclip ~/paperclip-teams
# Creates ~/paperclip-teams/review-crew/ with:
# TEAM.md, PROJECT.md, COMPANY.md, agents/.../AGENTS.md, tasks/.../TASK.md
