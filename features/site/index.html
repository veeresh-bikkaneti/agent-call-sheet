How to play

You're the location scout. Walk the camp, visit each district and read its postcard. Each one you read sends water down a canal, and the garden there grows back.

  • Move: WASD or arrow keys, a gamepad stick, or tap or click where you want to go.
  • Read a postcard: Enter or Space when you're close, the A button, or tap the building.
  • Look around: drag to pan, scroll or pinch to zoom.
  • Menus: Esc or Start to pause, G for the gallery, F for photo mode, M for sound.

Nothing here can be failed. Hidden landmarks near the edges hold extra postcards.

      The Agent Call Sheet

      Every agent on the call. Every role cast. Every task on a card. One builder's AI crew system, packaged as a library plus a front door, named for the film-crew call sheet that lists the whole cast and who is called for what.

      Layer 1: The Library

      The toolbox: 142 entries in six packs. Every entry records its author, its source, the license evidence found, and whether its files are included here or linked only. Nothing is copied on an assumption.

      • Crew Personas (41): reality checker, architects, developers, reviewers, test, security, AI, design, product and research seats.
      • Rigor (17): the discipline stack, from karpathy-guidelines to production-path verification.
      • Memory & Comms (4): output shaping plus memory and catch-up practices.
      • Design / Video / 3D (45): Remotion, Three.js, UI/UX and frontend design skills.
      • SEO (33): one leaf skill per job, from canonical tags to Core Web Vitals.
      • Legal (2): legal-advisor and gdpr-privacy.

      Read the manifest

      Layer 2: The Front Door

      The way in. If you install nothing else, install this.

      • Starter prompt: 11 house rules, among them remember the user, think in graphs, evidence first, blocked means blocked, and done means verified.
      • Crew Orchestrator: a skill that turns your host agent into a crew coordinator. It runs confirm, plan, build, test, independent gate, report, and it never certifies its own work.
      • Install guides: Claude Code, Claude web, Grok Build, Grok web and prompt-only, with verified and unverified claims labelled.

      Layer 3: Bootstrap

      One command copies the front door and the Rigor core set into place. It uses the Python standard library only, fetches nothing and runs nothing it copies.

      python3 features/paperclip-bridge/bootstrap.py --list      # preview, writes nothing
python3 features/paperclip-bridge/bootstrap.py --minimal   # just the front door
python3 features/paperclip-bridge/bootstrap.py --template review-crew

      A bare run targets Claude Code. Use --target claude-web, grok-build or prompt-only to stage files for upload or paste.

      Layer 4: The Live Debugger

      Watch a crew while it works, and step in.

      • Board server: a live stream of every agent's task, phase and status.
      • Nudge: bring back an agent that went silent on an open claim.
      • Intervene: pause, resume, redirect, reassign or stop a run.
      • Guard rails: 60 requests a minute plus a burst of 10, and an optional Bearer token.

      Open the board in demo mode · Live debugger notes

      Layer 5: The Paperclip Bridge

      Carry a crew to another platform. --export-paperclip DIR writes portable definitions: TEAM.md with its includes, PROJECT.md with an owner, COMPANY.md with the council rules, TASK.md with recurrence and assignee, and an AGENTS.md per agent with its skills.

      Water Gauge: the eval harness

      The harness re-checks the manifest against the files on disk, recomputes versions from git history, and runs negative controls that must fail. A check that couldn't run is reported as not run, never as a pass.

      python3 features/eval/eval/run_evals.py
