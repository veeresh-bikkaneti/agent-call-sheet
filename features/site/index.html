The Problem 零

AI Agent Crews Are Hard to Start

You want to run a crew of AI agents — a reality checker, an architect, a developer, a reviewer — each with a defined role. But the tooling is fragmented:

  • No shared manifest of who does what
  • No live view of what the crew is doing
  • No way to intervene mid-run when an agent goes silent
  • No portable format to move crews between platforms
  • No independent gate — agents self-certify

You end up managing chat threads instead of running a crew.

Proof — Live Collaboration Debugger 五

Watch Live, Intervene

Run the board server to watch crews live, send nudges, intervene mid-run. Rate limited (60 req/min + 10 burst). No auth — run on trusted network only.

# Terminal 1: Start server python3 front-door/board_server.py --run-file crew-run.jsonl --port 8765 # Terminal 2: Test endpoints curl http://127.0.0.1:8765/state curl -X POST http://127.0.0.1:8765/events -H "Content-Type: application/json" -d '{"agent":"test","task":"x","phase":"BUILD","status":"running","artifact":"x"}' curl -X POST http://127.0.0.1:8765/nudge -H "Content-Type: application/json" -d '{"agent":"test","message":"wake up"}' curl -X POST http://127.0.0.1:8765/intervene -H "Content-Type: application/json" -d '{"action":"pause","agent":"test"}'

SSE Stream

Real-time updates via GET /stream. Board reconnects auto on disconnect.

Nudge Silent Agents

POST /nudge — sends a message to a silent agent. Board shows "Nudged" badge.

Intervene Mid-Run

POST /intervene — pause, resume, redirect, reassign, or stop_run. Dynamic form per action.

Rate Limited

Token bucket: 60 req/min + 10 burst. Returns 429 with Retry-After header.

Architecture Visualization 七

3D Explorer

An interactive cinematic architecture visualization built in the Kage style. Drag to orbit, scroll to journey through five layers, click cards to explore. Built with Three.js r158, vanilla JS, no framework. SRI hashes + CSP require-sri-for script enforced.

Five Layers: Library (6 packs) → Front Door (starter prompt + orchestrator) → Bootstrap (bootstrap.py) → Live Debugger (board server + live_debugger.py) → Paperclip Bridge (export).

Open 3D Visualization

The console puts the eight findings of the independent gate verdict on a container yard, each with the status a fresh probe gives it, and lets you read them one at a time. It runs nothing: no server, no Python, no third-party script until you press deploy.
