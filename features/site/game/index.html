Quest 1 of 7

Get the kit

You need git and Python 3 (the standard library is enough; there is nothing to pip install). Every command after this runs from the repo root.

git clone https://github.com/veeresh-bikkaneti/agent-call-sheet.git
cd agent-call-sheet

You should see: git downloads the repo, and after the second command your terminal is inside the agent-call-sheet folder. (Not verified by our docs build: it is a network action.)

Quest 2 of 7

Peek before you commit

The list flag prints the plan and writes nothing: the read-the-call-sheet move.

python3 features/paperclip-bridge/bootstrap.py --list

You should see: a plan with the target, the destination and each entry it would copy. On our run it listed 17 include lines for the default set.

Quest 3 of 7

Install (Claude Code, the default)

A bare run targets Claude Code and copies the front door plus the Rigor core set into ~/.claude/skills. For the lightest footprint, use the minimal flag.

python3 features/paperclip-bridge/bootstrap.py
python3 features/paperclip-bridge/bootstrap.py --minimal

You should see: a copy summary. In our check with a scratch destination, the default run copied 151 files with 0 conflicts, and the minimal run copied 2 files.

Check that it landed

There is no command here. Start a new session in your assistant and ask it to confirm it can see the crew-orchestrator skill by name.

You should see: the assistant names crew-orchestrator. If it cannot, do not assume it loaded.

Quest 5 of 7

Add packs when real work calls for them

Add packs one at a time, vetted first. See what each pack contains on the market.

python3 features/paperclip-bridge/bootstrap.py --packs seo,legal

You should see: the extra pack entries added to the copy summary. Not verified by our docs build: an install with packs was not run, so read the output carefully.

Quest 6 of 7

Or cast a named crew

A crew template is a small JSON file. Preview it first, then install it. Replace FILE and DIR with your own paths.

python3 features/paperclip-bridge/bootstrap.py --template review-crew --list
python3 features/paperclip-bridge/bootstrap.py --template review-crew
python3 features/paperclip-bridge/bootstrap.py --template review-crew --export-crew FILE
python3 features/paperclip-bridge/bootstrap.py --import-crew FILE
python3 features/paperclip-bridge/bootstrap.py --template review-crew --export-paperclip DIR

You should see: the preview lists the crew's seats and writes nothing. Installing review-crew copied 15 files in our check with a scratch destination.

Quest 7 of 7

Watch a crew work on the live board

The board is a small server on your own machine that watches a run file. Try it with the sample run, then with your own.

python3 features/live-debugger/board_server.py --run-file features/eval/sample-run.jsonl
python3 features/live-debugger/board_server.py --run-file crew-run.jsonl
python3 features/live-debugger/live_debugger.py --run-file demo-run.jsonl
curl http://127.0.0.1:8765/state
BOARD_AUTH=1 BOARD_AUTH_TOKEN=mysecret python3 features/live-debugger/board_server.py --run-file crew-run.jsonl --host 0.0.0.0

You should see: the server prints the address it listens on, by default http://127.0.0.1:8765/. Open it in a browser. In our check the state address answered 200 (HTTP only, not viewed in a browser). The last command is bash syntax and turns on token auth for a wider bind.
