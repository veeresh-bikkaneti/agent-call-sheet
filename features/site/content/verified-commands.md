## Discrepancies between docs and actual scripts

- D1. Install guides give `python3 bootstrap.py ...` "from the repo root" (claude-code.md:5, claude-web.md:5, grok-build.md:5, grok-web.md:5, prompt-only.md:5; BEGINNER-GUIDE.md:28, 53, 56, 87, 133; templates.md:185-260). There is no `bootstrap.py` at the repo root. The real path is `features/paperclip-bridge/bootstrap.py`, which README.md:20, 65, 66, 90 use correctly. The site guide should use the full path.
- D2. BEGINNER-GUIDE.md:67, 74, 134; live-debugger.md:11, 199, 286, 369-370; README-board-server.md:9, 12 use `front-door/board_server.py`, `front-door/live_debugger.py`, `front-door/sample-run.jsonl`. None exist under `front-door/`. Real locations: `features/live-debugger/board_server.py`, `features/live-debugger/live_debugger.py`, `features/eval/sample-run.jsonl`. The server's built-in `/sample-run.jsonl` route returns 404 here (board dir `features/live-debugger/` has no such file; tested). README-board-server.md:33 uses bare `board_server.py`, valid only from inside `features/live-debugger/`.
- D3. `--bundle` fails on a default Windows checkout (row 9, CRLF). README.md:93 and the claude-web guide present it as working.
- D4. EVAL-GATE.md:18 records a PASS verdict, but a fresh `run_evals.py` run here reports 87 tier-1 FAILs and 4 tier-2 FAILs (row 18). Not investigated further.
- D5. Docs say `python3`; on this Windows machine the interpreter is `python`. The guide should say "python (or python3)".
- No flag mismatches: every flag in the docs I checked exists in argparse (bootstrap `--target --dest --packs --template --import-crew --export-crew --export-paperclip --force --list --minimal --explain --bundle`; board_server `--run-file --port --host --silence --extra-run --board-dir`; live_debugger `--run-file --server`).

## Live board quick reference

- Start: `python features/live-debugger/board_server.py --run-file crew-run.jsonl` (`python3` on macOS/Linux).
- URL/port: default `http://127.0.0.1:8765/`; the server prints the actual URL on start. Change with `--port N`.
- Point at a run file: `--run-file PATH` (JSONL; created if absent per source). Extra files with repeatable `--extra-run PATH`, served at `/runs/<name>`.
- Endpoints verified: `/` 200, `/state` 200, `/stream` 200 (SSE), `/events` GET 405 (POST only).
- Remote bind: `--host 0.0.0.0` prints a warning and requires `BOARD_AUTH` (help text, board_server.py:804-805).
- Without a server, `features/live-debugger/board.html` can replay a run file by hand (README.md:69); not opened in a browser here.
