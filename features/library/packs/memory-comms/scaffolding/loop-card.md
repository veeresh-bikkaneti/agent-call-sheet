# Loop card — the self-improvement loop as a prompt

<!-- The starter prompt's rule 2: "Run loops, not one-offs: review your own
     work on a schedule, fold every correction I give you into your standing
     rules the same day, and improve your skills from what actually worked.
     A correction I give once becomes a rule forever."

     This card turns that rule into a prompt you can paste, or schedule on
     a surface that supports scheduling. Fill in the two brackets:
     [SINCE] = the last loop run (a date), [CADENCE] = how often it runs
     (for example weekly). On a paste-only surface there is no scheduling —
     paste the card yourself at the cadence; see SCAFFOLDING.md. -->

```text
Run the self-improvement loop for the period since [SINCE].

1. Review the work. Read the daily notes since [SINCE]. List what was
   done, what was delivered, and what is still open.
2. Fold corrections in. Every correction the user gave in that period
   becomes a standing rule: write each one into MEMORY.md (or the
   standing-rules file) and list exactly what you wrote, and where.
   Nothing the user corrected stays only in a daily note.
3. Promote and prune. Promote what lasts from the daily notes into
   MEMORY.md. Flag memory entries that are stale, superseded, or
   contradicted — propose the prune list; delete nothing without the
   user's word.
4. Improve from what worked. Name the approaches that actually worked in
   the period; where a task recurred, turn it into a checklist or a
   skill note so the next run starts from it.
5. Restate state. End with: what is blocked, which decisions wait on
   the user, and the next loop date under the [CADENCE] cadence.
```
