Architecture Visualization

Interactive cinematic 3D explorer of the Agent Call Sheet system. Five layers, scroll-synced, drag to orbit.

Five Layers

Layer 1 — Library (6 packs)

142 entries: Crew Personas (41), Rigor (17), Memory/Comms (4), Design/Video/3D (45), SEO (33), Legal (2). Each with author, source, license evidence, SHA-256.

Layer 2 — Front Door

Starter Prompt — 11 house rules. Crew Orchestrator — turns host agent into coordinator. Phases: confirm → plan → build → test → independent gate → report.

Layer 3 — Bootstrap

bootstrap.py — installs front door + packs. --minimal (2 files), --packs (incremental), --template (named crews), --export-paperclip (portable definitions).

Layer 4 — Live Debugger

Board Server (SSE) + Intervention API (pause/redirect/reassign/stop) + Debugger Library. Rate limited (60 req/min + 10 burst). Optional Bearer token auth.

Layer 5 — Paperclip Bridge

Export portable team: TEAM.md (includes[]), PROJECT.md (owner), COMPANY.md (council rules), TASK.md (recurring+assignee), AGENTS.md (skills[]).

Interactive 3D View

The Three.js visualization loads on first interaction (scroll, click, or keypress) — respecting your bandwidth and prefers-reduced-motion.
