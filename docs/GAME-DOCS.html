Agent Call Sheet

A game-style walkthrough for running AI agent crews. No fluff. Just the path.

LVL 1Clone & Inspect

Objective

Get the repo locally. Verify integrity before you trust it.

$ git clone https://github.com/veeresh-bikkaneti/agent-call-sheet.git $ cd agent-call-sheet $ ls -la # verify structure
  • Repo cloned
  • bootstrap.py exists at root
  • front-door/, packs/, docs/ present
  • MANIFEST.md and manifest.csv present
LVL 2Minimal Install (2 files)

Objective

Install ONLY the front door (orchestrator + starter prompt). No packs. No bloat. Test the core loop works.

$ python3 bootstrap.py --minimal --dest /path/to/your/skills
Expected output: Setup complete: 2 files copied — crew-orchestrator/ + starter-prompt.md
  • Install succeeds with 2 files
  • INSTALL-RECEIPT.json generated
  • Skills folder has crew-orchestrator/ and starter-prompt.md
⚠ Destination must be OUTSIDE the repo. The script refuses paths inside the cloned directory. Use ~/skills or /tmp/test-skills.
LVL 3First Crew Run (Zero-Install Path)

Objective

Run a crew without installing anything. Paste the starter prompt into your AI assistant.

$ cat front-door/starter-prompt.md # Copy the ENTIRE output # Paste into Claude Code / Claude Web / Grok / etc.
  • Starter prompt copied
  • Pasted into your AI assistant
  • Assistant acknowledges house rules (11 rules)
  • Assistant asks for your target/task
⚠ This path needs no files installed. Works on any surface that accepts prompts.
LVL 4Full Install — Add Packs

Objective

Add specialist packs. Start with Rigor (discipline stack), then add what you need.

# See what packs exist $ python3 bootstrap.py --list --explain # Install Rigor (17 discipline skills) $ python3 bootstrap.py --packs rigor --dest ~/skills # Or add multiple packs $ python3 bootstrap.py --packs rigor,seo,legal --dest ~/skills
Rigor pack adds: ponytail, archify, graphify, karpathy-guidelines, agents-orchestrator, production-path-verification, and 11 more discipline skills.
  • --list --explain shows descriptions
  • Pack install completes without conflicts
  • Skills appear in your AI's skill list
LVL 5Live Board Server

Objective

Run the board server to watch crews live, send nudges, intervene mid-run.

# Terminal 1: Start server $ python3 front-door/board-server.py --run-file crew-run.jsonl --port 8765 # Terminal 2: Test endpoints $ curl http://127.0.0.1:8765/state $ curl -X POST http://127.0.0.1:8765/events -H "Content-Type: application/json" -d '{"agent":"test","task":"x","phase":"BUILD","status":"running","artifact":"x"}'
  • Server starts on http://127.0.0.1:8765/
  • GET /state returns folded run
  • POST /events returns 201
  • POST /nudge works
  • POST /intervene works (pause/resume/redirect/reassign/stop_run)
⚠ No authentication. Runs on 127.0.0.1 only. Rate limited to 60 req/min + 10 burst.
# Live board URL (opens in browser) $ open http://127.0.0.1:8765/
LVL 6Paperclip Export

Objective

Export your crew as a portable Paperclip team (TEAM.md, PROJECT.md, COMPANY.md, TASK.md, AGENTS.md).

$ python3 bootstrap.py --export-paperclip /path/to/output --template review-crew
  • Output dir created with TEAM.md, COMPANY.md, PROJECT.md
  • agents/ dir with agent definitions
  • projects/ and tasks/ populated
